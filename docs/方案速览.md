# 方案速览（一页）

**是什么**：基于 CAD 的仓配/物流 OD 矩阵仿真 + Godot 本地 3D 回放。  
**给谁用**：公司内 Mac M4 本机部署，全开源，不用 CUDA。  
**核心栈**：Python/SimPy（算） + Godot 4（看） + Blender（可选美化）。

## 三步上手

```bash
./scripts/run_demo.sh          # 生成地图 + 仿真 + KPI
# 用 Godot 打开 godot/project.godot 回放
./scripts/run_api.sh           # 可选：本机调参 API
```

## 自有 CAD

DXF 按 `docs/CAD图层规范.md` 分层 → `python -m tools.dxf_to_map --input data/raw/plant.dxf` → 改 OD → 再仿真。
