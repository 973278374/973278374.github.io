# 开源依赖清单（可审计）

本方案运行时 **不包含** CUDA、NVIDIA 专有运行时、Isaac Sim。

| 组件 | 用途 | 许可 | 本地 |
|------|------|------|------|
| Python 3.12 | 运行时 | PSF | ✅ |
| SimPy | DES 仿真 | MIT | ✅ |
| NetworkX | 导航图 / 路径 | BSD | ✅ |
| Shapely | 几何 | BSD | ✅ |
| ezdxf | DXF 读取 | MIT | ✅ |
| NumPy / Pandas | 数值与表 | BSD | ✅ |
| PyYAML | 场景配置 | MIT | ✅ |
| FastAPI / Uvicorn | 本机 API | MIT | ✅ |
| Godot 4 | 3D 回放 | MIT | ✅ |
| Blender | 资产 / 离线渲 | GPL-2.0+ | ✅ |
| FreeCAD（可选） | CAD 清洗 | LGPL | ✅ |

## 明确不引入

- CUDA Toolkit / cuDNN  
- NVIDIA Isaac Sim / Omniverse  
- 闭源物流仿真 SaaS 运行时  

## 公司合规建议

1. 将本清单附入内部开源引入申请  
2. Godot/Blender 使用官方 Apple Silicon 构建  
3. 仿真与演示默认绑定 `127.0.0.1`，不暴露公网
