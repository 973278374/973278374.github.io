# 公司落地操作手册（Mac M4）

## 角色与分工

| 角色 | 任务 |
|------|------|
| 工艺/物流 | 提供 CAD、OD 矩阵、车速/装卸节拍 |
| IT/仿真 | 维护本仓库、跑仿真、出 KPI |
| 演示 | Godot 回放 / Blender 出片 |

## 第一次部署（约一次性）

1. Mac 安装 Homebrew、Python 3.12、Godot 4、Blender（Apple Silicon）
2. `git clone` 本仓库 → `./scripts/run_demo.sh`
3. 确认 `data/output/kpi.json` 生成；Godot 能打开回放

## 接入自有 CAD

1. DWG → DXF，按 `docs/CAD图层规范.md` 改图层  
2. 文件放到 `data/raw/plant.dxf`  
3. `python -m tools.dxf_to_map --input data/raw/plant.dxf --out data/processed`  
4. 若单位为毫米：加 `--unit-scale 0.001`  
5. 更新 `scenarios/od_matrix.csv` 的起终点 ID 与库位/月台一致  
6. `python -m sim.run --scenario scenarios/demo.yaml`  
7. 复制轨迹到 `godot/data/` 后回放  

## 调参

- 车数 / 时长：改 `scenarios/demo.yaml` 或 `POST http://127.0.0.1:8000/api/run`  
- 启动 API：`./scripts/run_api.sh`（仅本机回环）

## 合规

- 不安装 CUDA / Isaac  
- 依赖见 `docs/开源依赖清单.md`  
- 演示默认不访问公网
